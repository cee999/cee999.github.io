Selected work

Omnicee

A decision-support platform where several software “agents” each look at the market in a different way and vote on trade signals. Before a signal goes out, it is checked with probability calibration, Monte Carlo and Bayesian tests, and risk gates. A React dashboard installs as an app and also runs inside Telegram.

I built it alone and deployed it on Render with MongoDB Atlas. I fixed real production problems along the way, such as region blocks and slow cold starts. It pulls from several live data feeds with backups if one fails, and sign-in works with an email code. See the code on GitHub.

Python · FastAPI · React · MongoDB Atlas · Render · Brevo

Face-recognition attendance system
